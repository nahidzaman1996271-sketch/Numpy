# 🔢 Numpy

A structured, hands-on collection of notes and exercises for learning NumPy — Python's core library for numerical computing.

## 📂 Topics Covered

- **Introduction** — getting started with NumPy
- **Creation** — building arrays from scratch
- **Array Properties** — shape, size, dtype, and more
- **Indexing and Slicing** — accessing and selecting array data
- **Reshaping and Manipulating** — changing array structure
- **Broadcasting** — operating on arrays of different shapes
- **Vectorization** — writing fast, loop-free array operations
- **Handling Missing Values** — dealing with NaNs and gaps in data
- **Advanced Numpy** — deeper, more advanced concepts

## 🛠️ Tech Stack

Python • NumPy

## 🎯 Purpose

This repo tracks my progress learning NumPy fundamentals — one topic at a time — building toward the numerical computing skills needed for data science and machine learning work.
